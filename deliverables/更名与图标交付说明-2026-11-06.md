## 二、数据目录迁移（改名唯一会伤到用户的地方，已兜底）

新目录 `%LOCALAPPDATA%\ThermalTuner`，旧目录 `%LOCALAPPDATA%\ThermalPilot`。
`SettingsStore.ResolveDataDirectory()` 在首次启动时：

1. 若新目录已有 `migrated-from-legacy.txt` → 跳过（只迁一次）；
2. 否则把旧目录内容**复制**到新目录（已存在的文件不覆盖）；
3. 写迁移标记；**旧目录保留不删**；
4. 任何异常都吞掉不阻断启动。

`StartupRegistration.CleanupLegacy()` 在 UI 启动时清理旧 HKCU Run 项，
**仅当该值明确指向 `ThermalPilot.App.exe` 时才删**，避免误伤同名项。

### 实测证据（2026-11-06 18:57，本机）

```
旧目录: backup/ capability.json logs/ settings.json
新目录: backup/msr-{startup,epp-startup,turbo-startup,voltage-startup}.json
        capability.json  logs/msr-audit.log  settings.json
        migrated-from-legacy.txt
settings.json 关键值新旧一致: ReplayOnStartup=true / TauS=32 /
        VoltageWritable=false / EnvironmentChecked=true
```

发布包管理员 `--env-check` 回读 `Tau 32s`，证明**迁移后的配置确实被重放到寄存器**，
而不是只有文件被复制。报告：`deliverables/env-check-ThermalTuner-release-2026-11-06.txt`。

## 六、体验包与验证步骤

**包（用新名字）**

- `dist/ThermalTuner-v0.4.3-2026-11-06/ThermalTuner.App.exe`（157.41 MB，自包含，免装 .NET 8）
- `dist/ThermalTuner-v0.4.3-2026-11-06-win-x64.zip`（63.85 MB）

`dist/` 已被 `.gitignore` 排除。旧目录（含 `-r2` 等历史包）保留但**不要再用**。

**建议按顺序**

1. 看资源管理器里 exe 的图标是否为深蓝 + 青色曲线；双击后看窗口左上角、任务栏、托盘图标是否一致。
2. 「诊断与日志」看环境自检报告，确认 `LHM 0.9.4.0 / WinRing0 / Writable`。
3. 「高级参数」确认原标定/微调值还在（`Tau 32s`、`VoltageWritable=false` 的电压项仍禁用）。
4. 管理员跑 `ThermalTuner.App.exe --env-check --out env-check.txt` 复核能力矩阵。
5. 确认旧配置无误后，可手动删除 `%LOCALAPPDATA%\ThermalPilot`（程序不会自动删）。
