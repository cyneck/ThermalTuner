# 监控面板指标扩展说明

生成时间：2026-11-06　范围：实时监控页新增 CPU 使用率 / GPU 使用率 / GPU 显存占用率 / 风扇

---

## 一、四项指标的数据源与口径

| 指标 | 数据来源 | 本机实测 | 口径 |
| :--- | :--- | :--- | :--- |
| CPU 使用率 | LHM `Load / CPU Total` | 35.7% | 全核总负载；驱动不可用时回退 `GetSystemTimes` 计算 |
| GPU 使用率 | 独显 `Load / GPU Core`（优先 NVIDIA/AMD）；核显回退 `D3D *` 负载峰值 | 0.0%（空闲） | 独显为精确值；核显标 `D3D/共享显存`，属近似 |
| GPU 显存占用率 | `Load / GPU Memory`；缺失时由 `SmallData / GPU Memory Used ÷ Total` 计算 | 1.9%（78 / 4096 MB） | 同卡显示「已用 / 总量 MB」，悬停可见 |
| 风扇 | `SensorType.Fan`（RPM）或 `SensorType.Control`（%） | **N/A** | 本机主板 `HP 838F` 未暴露任何 Fan/Control 传感器 |

**风扇的产品口径（重要）**：软件**从不写**风扇 / EC / PWM，风扇由 EC 按温度曲线自动调速。
决策树里的 `TargetFanPercent` 只是**演算建议值、未下发**，与本次新增的「实测风扇」严格分开；
本机读不到传感器时 UI 直接显示 `N/A` 并标注「本机 EC 未暴露」，**不拿演算值冒充实测**。
换一台能读到 Fan/Control 传感器的机器，同一份代码会自动显示实测 RPM 或控制百分比。

## 二、实现

| 文件 | 改动 |
| :--- | :--- |
| `Services/HardwareTelemetry.cs` | `Computer` 启用 `IsGpuEnabled` / `IsMotherboardEnabled`；`TelemetrySample` 扩展 8 个可选字段；新增 `ReadGpu()` / `ReadFan()` / `WithExtras()`；`DumpSensors()` 改为列出全部硬件 |
| `Services/SessionState.cs` | 逐拍刷新扩展指标，暴露 `CpuLoadText` / `GpuLoadText` / `GpuMemoryText` / `GpuMemoryDetailText` / `FanMeasuredText` / `FanMeasuredHintText` / `GpuNameText` 等绑定属性 |
| `Views/MonitorPage.xaml` | 明细区上方新增一行 4 列紧凑指标卡（标签 / 数值 / 来源），详情放 ToolTip；**不新增页面、不堆说明文字** |
| `Views/MonitorPage.xaml.cs` | 导出文件名残留 `thermalpilot-` 修正为 `thermaltuner-` |
| `SensorProbe.cs` + `App.xaml.cs` | 新增只读 `--sensor-probe` 命令：枚举全部 LHM 硬件/传感器，并输出一拍聚合指标，便于换机核实可得性 |

设计约束：扩展指标读取失败一律返回 `NaN` 并被 `WithExtras` 吞掉，**不影响温度 / 功耗 / 决策树主链路**；
GPU Update 与主板 Update 每拍一次（1 Hz），不额外打开 MSR 句柄。
