== 5. 判定 ==
最高功耗场景     : SIMD_FULL（SimdFma / 8 线程） 峰值 43.93 W
相对默认功率     : 98%（默认 45.0 W）
可触发功耗墙场景 : FLOAT_FULL 起即可达目标覆盖率，后续 A/B/C 降墙压测应至少使用该场景。
   → 峰值已贴近实读 PL1，负载确实顶到了功耗墙；此时放宽 PL1 才可能带来收益，
     而把 PL1 压到该峰值之下会立刻钳制（前提：Tau 为秒级短窗口，否则短时压测看不到钳制）。

== 6. 边界说明 ==
· 本探针只读：不写 0x610 / 0x774 / 0x1AD，不碰风扇 / EC / PWM / 电源计划 / 电压。
· 风扇由 EC 按温度曲线自动调速，软件只能通过改变发热量间接影响转速。
· 默认功率取 MsrGuard 启动时备份的固件出厂默认 PL1，不是硬编码常量，也不是重放后的当前值。
· 固件默认值不可持久化修改；软件只持久化标定与微调结果，开机重放写入 0x610，退出后 CPU 回到固件默认。
· 场景功耗受电源计划、散热状态、后台负载影响，换机或换散热条件应重跑本扫描。
