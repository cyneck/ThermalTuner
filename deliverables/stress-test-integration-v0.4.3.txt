== 2. 软件到底会动哪些参数（代码事实）==
· 通道后端：LHM 0.9.4 / WinRing0 (Ring0.WriteMsr)。0.9.4 自带 WinRing0 内核驱动，可读可写 MSR。
· 写 MSR 0x610（PKG_POWER_LIMIT）：PL1 长时功耗墙 / PL2 短时爆发墙 / Tau 平均窗口。
· 写 MSR 0x774 [31:24]：HWP EPP 能效偏好（本机 0x774 可读，写后回读校验）。
· 只读 MSR 0x606 / 0x611（或 AMD 0xC0010299 / 0xC001029B）：RAPL 能量单位与能量计数器，用于算真实包功耗。
· MSR 0x1AD 睿频倍率 / 0x150 FIVR 电压偏移：本机可读可写（老版本实现过），当前版本暂未接入，不写。
· 风扇 / EC / PWM：代码中不存在任何写入。决策树里的 TargetFanPercent 只是动作字段，未落到硬件；
  风扇转速由固件/EC 按温度曲线自行调节，软件只能通过降低发热间接影响它。
· 电源计划 / 最大频率：软件不碰（powercfg 对照在本机无效，已从压测移除）。

== 7. 关键判定 ==
① 满载是否触及固件功耗墙 : 峰值包功耗 33.9W / 固件 PL1 45.0W = 75%
   → 本机在该负载下根本没顶到 PL1 天花板。把 PL1 调高（如 49W / 65W）不会产生任何可观测差异，
     这正是『智能调优没有直观感受』的核心原因之一：调的是上限，而实际功耗远在上限之下。
② 决策值是否落到寄存器     : 决策 PL1 均值 60.2W / 0x610 实读均值 45.0W
   → 压测期间已临时关闭「自动接管」，决策值仅作参考；本段寄存器保持固件默认值，
     A/B/C 的降墙/放宽由压测脚本手动下发（见第 4 节切换记录与 ④ 实读对照）。
③ 热模型校验               : 空载→满载 ΔT=8.56°C / ΔP=14.20W = 短时斜率 0.603 K/W；稳态标定 Rth=0.908 K/W
   → 短时斜率通常小于稳态 Rth：40 秒还没走到热稳态（本机 Tau≈8h，热容很大），
     两点稳态法测出的 Rth 只适合做长期稳态外推，不适合解释瞬时升温速度。

④ 写入式 A/B/C 对照（0x610 实读随阶段变化，参数生效的直接证据）:
阶段                实读PL1W     均温°C      均功耗W     均频GHz
LOAD_FW             45.0     68.3     33.41      3.41
LOAD_LOW            15.0     55.2     14.96      2.23
LOAD_HIGH           65.0     68.5     33.23      3.41
   → 0x610 实读由 45.0W → 15.0W → 65.0W，证明软件确实把 PL1 写进了 CPU 寄存器（不是只算不写）。
   → 降墙段：均温 68.3 → 55.2°C（ΔT=-13.09°C），均功耗 33.4 → 15.0W（ΔP=-18.45W）。
   → 放宽段：实读 65.0W，但均功耗 33.2W 仍远低于该墙，所以放宽 PL1 不产生可观测变化（调的是天花板）。
   注：降墙/放宽阶段同时把 Tau 从固件 28672s 缩到 8s，否则超长平均窗口下短时压测看不到限功耗。
⑤ 定量外推（稳态）         : 把 PL1 从 45.0W 降到 15.0W，按稳态热阻 0.91 K/W，长期稳态温度预计下降约 16.7°C；
   把 PL1 放宽到 65.0W 则预计 <1°C 变化（实际功耗 33.4W 远低于墙）。
   注意：这是稳态估计，短时实测降温幅度会因热容偏小（见 ③）。

== 8. 结论汇总 ==
1) 通道 LHM 0.9.4 / WinRing0 (Ring0.WriteMsr) 可用：软件真实读写 MSR 0x610（PL1/PL2/Tau）与 0x774（EPP）；
   风扇 / EC / PWM / 电源计划一律不碰；0x1AD 睿频倍率、0x150 电压偏移本机可写，当前版本暂未接入。
2) 本次实测：同值写回 → 回读 → 恢复全链路 PASS；压测中 0x610 实读随阶段从固件默认变为降墙/放宽值，
   收尾已恢复固件默认值。『软件只算不写』的判断已被实测推翻。
3) 参数生效条件：PL1 是功耗天花板，只有压到实际满载功耗之下才有效；
   本机满载峰值 33.9W（固件 PL1 45.0W 的 75%），放宽到 65W 无意义，压到 15W 才有限制作用。
4) 固件 Tau≈28672s 是超长平均窗口，短时压测必须同时缩短 Tau 才能观察到钳制；
   风扇仍由 EC 按温度曲线自动调速，软件通过少发热间接降速，不直接拨风扇。
5) 上一轮『本机不可写』结论有误：根因是 LHM 从 0.9.4 升到 0.9.6 后驱动后端变为只读 PawnIO 模块；
   本版已回退到 0.9.4 WinRing0 通道并实机验证。
